Exercise 1
=======================

Reorder the following code snippets to create a function that finds the maximum value in a list of numbers.


.. ordering::

    def find_max(numbers):
        max_val = numbers[0]
        for num in numbers:
            if num > max_val:
                max_val = num
        return max_val
